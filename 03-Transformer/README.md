# 第三阶段：Transformer 基础

## 学习目标
- 理解 Transformer 架构原理
- 掌握 Self-Attention、Multi-Head Attention、Positional Encoding
- 从零实现一个 mini-Transformer
- 熟悉 Hugging Face Transformers 库

## 学习资源
- 原论文 Attention Is All You Need：https://arxiv.org/abs/1706.03762
- The Annotated Transformer：http://nlp.seas.harvard.edu/annotated-transformer/
- Hugging Face 官方教程：https://huggingface.co/docs/transformers/index

## 核心知识点
- Self-Attention 机制（Q、K、V）
- Multi-Head Attention
- Positional Encoding（位置编码）
- Layer Normalization
- Feed-Forward Network
- Encoder-Decoder 架构

## 练手项目
- 从零实现 mini-Transformer（参考 Annotated Transformer）
- 使用 Hugging Face 进行文本分类/翻译微调

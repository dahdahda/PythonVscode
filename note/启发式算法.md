# 启发式算法

柔性作业车间调度问题需要依次解决两个核心问题：

1. **工序排序**：下一步优先安排哪个工件的哪道工序？
2. **机器分配与时间安排**：选中的工序应分配到哪台机器，并在什么时间加工？

本项目使用 MOPNR 或 MWKR 构造工序优先队列，使用 SPT 或 EET 完成机器选择。两类规则交叉组合，形成四种启发式算法：MOPNR-SPT、MOPNR-EET、MWKR-SPT 和 MWKR-EET。

## 一、工序优先规则

工序优先规则决定下一步从哪个工件中取出一道工序。无论使用 MOPNR 还是 MWKR，同一工件内部都必须遵守原有工艺顺序：前一道工序没有完成，后一道工序不能提前加工。

### 1. MOPNR：剩余工序数最多优先

MOPNR 是 **Most Operations Remaining** 的缩写，含义是“剩余工序数最多的工件优先”。

#### 基本原理

在调度过程的每个决策时刻，统计每个工件尚未安排的工序数量，然后选择剩余工序数量最多的工件，并将该工件当前最靠前的未安排工序加入优先队列。

假设有三个工件：

| 工件 | 剩余工序数 |
| --- | ---: |
| J1 | 4 |
| J2 | 2 |
| J3 | 3 |

此时 J1 的剩余工序数最多，因此优先选择 J1 的下一道工序。选择之后，J1 的剩余工序数由 4 减为 3，再重新比较三个工件。

这一过程会持续进行，直到所有工件的全部工序都进入优先队列。

#### 同分处理

当两个或多个工件的剩余工序数相同时，选择工件编号较小者。明确同分规则可以保证相同输入每次产生相同结果。

#### 规则特点

- 重点关注工序数量较多的工件，避免它们过晚开始。
- 只需要统计剩余工序数，计算简单、执行速度快。
- 不考虑每道工序实际需要的加工时间。
- 两个工件即使剩余工序数相同，实际剩余工作量也可能相差很大。

因此，MOPNR 适合快速构造可行的工序顺序，但“工序多”并不一定等同于“工作量大”。

### 2. MWKR：剩余工作量最大优先

MWKR 是 **Most Work Remaining** 的缩写，含义是“剩余工作量最大的工件优先”。

#### 基本原理

MWKR 不只计算工件还剩多少道工序，还估计这些工序总共需要多少加工时间。在每个决策时刻，选择剩余估计工作量最大的工件，再取出该工件当前最靠前的未安排工序。

在柔性作业车间中，同一道工序可能由多台机器加工，并且加工时间可能不同。为了在尚未确定机器时估计工序工作量，本项目取该工序所有候选机器中的最短加工时间。

一道工序的估计工作量为：

$$
w_{j,o}=\min_{m\in M_{j,o}}p_{j,o,m}
$$

其中：

- $j$ 表示工件；
- $o$ 表示工序；
- $M_{j,o}$ 表示该工序的候选机器集合；
- $p_{j,o,m}$ 表示该工序在机器 $m$ 上的加工时间。

工件的剩余估计工作量等于所有尚未安排工序的估计工作量之和：

$$
W_j=\sum_{o\in R_j}w_{j,o}
$$

其中，$R_j$ 是工件 $j$ 尚未安排的工序集合。

#### 示例

假设有两个工件：

| 工件 | 剩余工序的最短候选加工时间 | 剩余估计工作量 |
| --- | --- | ---: |
| J1 | 3、4、2 | 9 |
| J2 | 6、5 | 11 |

虽然 J1 有三道剩余工序，J2 只有两道，但 J2 的剩余估计工作量更大。因此 MWKR 优先选择 J2，而 MOPNR 会优先选择 J1。

#### 状态更新

当某个工件的一道工序进入优先队列后，需要从该工件的剩余工作量中扣除这道工序的估计工作量，然后重新比较所有尚未完成的工件。

#### 同分处理

当多个工件的剩余估计工作量相同时，选择工件编号较小者。

#### 规则特点

- 同时反映剩余工序数量和加工时间，比单纯统计工序数包含更多信息。
- 能较早处理预计负担较重的工件，有助于降低长工件成为最终瓶颈的风险。
- 使用最短候选加工时间只是乐观估计，没有考虑机器当前负载和机器竞争。
- 实际机器分配完成后，真实剩余加工时间可能大于估计值。

### 3. MOPNR 与 MWKR 的区别

| 比较内容 | MOPNR | MWKR |
| --- | --- | --- |
| 排序依据 | 剩余工序数量 | 剩余估计加工时间总和 |
| 是否考虑加工时间 | 否 | 是 |
| 是否考虑机器负载 | 否 | 否 |
| 计算复杂度 | 较低 | 略高 |
| 优先关注对象 | 工序数量多的工件 | 预计工作量大的工件 |
| 主要局限 | 工序数量不能反映工序长短 | 工作量是乐观估计，未考虑机器竞争 |

MOPNR 回答的是“哪个工件还有更多步骤”，MWKR 回答的是“哪个工件预计还有更多工作”。

## 二、机器选择规则

工序优先队列确定后，需要为每道工序选择一台合法的候选机器。SPT 和 EET 都只能在该工序允许使用的机器中进行选择，不能把工序分配给候选集合之外的机器。

机器确定后，还需要同时满足两个时间条件：

1. 工序不能早于同一工件的前一道工序完成时间开始。
2. 工序不能与所选机器上已经安排的其他工序重叠。

### 1. SPT：最短加工时间优先

SPT 是 **Shortest Processing Time** 的缩写，含义是“加工时间最短的机器优先”。

#### 基本原理

对于当前工序，比较它在所有候选机器上的加工时间，选择加工时间最短的机器。选择机器之后，再根据工件就绪时间和机器已占用区间，寻找该机器上的最早可行开始时间。

假设某道工序有以下候选机器：

| 候选机器 | 加工时间 |
| --- | ---: |
| M1 | 8 |
| M2 | 5 |
| M3 | 6 |

SPT 会选择 M2，因为它的加工时间最短。

#### 同分处理

如果多台候选机器的加工时间相同，则选择机器编号较小者。

#### 规则特点

- 直接缩短当前工序本身的加工时间。
- 决策简单，不需要在选机阶段评价全部机器时间表。
- 不考虑候选机器什么时候能够开始加工。
- 可能把大量工序集中到少数加工速度快的机器上，形成机器拥堵。

例如，M1 加工只需 4 个时间单位但还要等待 20 个时间单位，M2 加工需要 7 个时间单位但可以立即开始。SPT 仍会选择 M1，因为它只比较加工时间，不比较最终结束时间。

### 2. EET：最早结束时间优先

EET 是 **Earliest End Time** 的缩写，含义是“能够让当前工序最早结束的机器优先”。

#### 基本原理

EET 会对每台候选机器分别进行一次时间安排评估：

1. 根据工件前一道工序的结束时间确定工件就绪时间。
2. 检查候选机器已经占用的加工区间。
3. 寻找不早于工件就绪时间的最早可行空隙。
4. 将最早开始时间与该机器上的加工时间相加，得到最早结束时间。
5. 比较所有候选方案，选择结束时间最早者。

其决策目标可表示为：

$$
m^*=\arg\min_{m\in M_{j,o}}
\left(S_{j,o,m}+p_{j,o,m}\right)
$$

其中：

- $S_{j,o,m}$ 是工序在机器 $m$ 上的最早可行开始时间；
- $p_{j,o,m}$ 是工序在机器 $m$ 上的加工时间；
- 两者之和是该方案的最早结束时间。

#### 示例

假设某工序在当前时刻有两个候选方案：

| 机器 | 加工时间 | 最早可开始时间 | 最早结束时间 |
| --- | ---: | ---: | ---: |
| M1 | 4 | 20 | 24 |
| M2 | 7 | 0 | 7 |

SPT 会选择加工时间更短的 M1，而 EET 会选择能够在时间 7 完成的 M2。虽然 M2 加工较慢，但无需长时间等待，因此工序能够更早结束。

#### 同分处理

当多台候选机器的最早结束时间相同时，本项目依次比较：

1. 最早开始时间，较早者优先；
2. 加工时间，较短者优先；
3. 机器编号，较小者优先。

#### 规则特点

- 同时考虑工件就绪时间、机器空闲时间和实际加工时间。
- 能主动避开当前较拥堵的机器，通常具有更好的负载平衡能力。
- 每次选机都要检查所有候选机器的时间表，计算量高于 SPT。
- 仍属于局部贪心决策，只保证当前工序尽早结束，不保证最终全局最优。

### 3. SPT 与 EET 的区别

| 比较内容 | SPT | EET |
| --- | --- | --- |
| 主要比较对象 | 加工时间 | 最早结束时间 |
| 是否考虑工件就绪时间 | 选机时不考虑 | 考虑 |
| 是否考虑机器当前负载 | 选机时不考虑 | 考虑 |
| 是否利用机器空隙 | 选机后安排时利用 | 评价每台候选机器时利用 |
| 计算量 | 较低 | 较高 |
| 主要风险 | 快速机器过度拥堵 | 当前最早结束未必有利于后续全局调度 |

SPT 回答的是“在哪台机器上加工得最快”，EET 回答的是“在哪台机器上能够最早完成”。

## 三、四种组合算法

### 1. MOPNR-SPT

先选择剩余工序数最多的工件，再为其当前工序选择加工时间最短的机器。

- 工序排序和机器分配都非常简单。
- 构造速度快。
- 既不考虑工件剩余加工量，也不考虑机器当前负载。
- 容易出现快速机器拥堵。

### 2. MOPNR-EET

先选择剩余工序数最多的工件，再选择能让当前工序最早结束的机器。

- 保留 MOPNR 简单的工序排序方式。
- EET 能根据当前机器时间表分散任务。
- 通常比 MOPNR-SPT 得到更小的最大完工时间。

### 3. MWKR-SPT

先选择剩余估计工作量最大的工件，再为其当前工序选择加工时间最短的机器。

- 工序排序考虑了加工时间差异。
- 机器选择仍不考虑机器拥堵。
- 当快速机器成为瓶颈时，仅改进工序排序可能无法明显改善结果。

### 4. MWKR-EET

先选择剩余估计工作量最大的工件，再选择能让当前工序最早结束的机器。

- 工件排序考虑剩余工作量。
- 机器分配考虑实际可用时间。
- 在当前四种算法中使用的信息最完整。
- 当前项目的基准结果中，MWKR-EET 的整体表现最好。

## 四、完整调度过程

四种算法的总体过程可以概括为：

1. 读取工件、工序、候选机器和加工时间。
2. 使用 MOPNR 或 MWKR 确定下一道待调度工序。
3. 使用 SPT 或 EET 为该工序选择候选机器。
4. 在所选机器的时间表中寻找最早可行空隙。
5. 记录工序的开始时间、结束时间和机器分配。
6. 更新工件完工时间及机器占用区间。
7. 重复上述过程，直到所有工序完成调度。
8. 检查工件工序顺序和机器任务是否重叠。
9. 计算最大完工时间并输出调度结果。

## 五、总结

四条启发式规则解决的是两个不同层面的决策：

- **MOPNR 与 MWKR** 决定“下一步优先处理哪个工件”。
- **SPT 与 EET** 决定“当前工序应选择哪台机器”。

MOPNR 使用剩余工序数衡量紧迫程度，MWKR 使用剩余估计工作量衡量负担；SPT 追求当前加工时间最短，EET 追求包含等待时间后的完成时刻最早。

这些算法都能快速产生可行解，但本质上仍是逐步做出局部决策的贪心算法。它们不能保证获得全局最优解，不过可以作为快速求解方法，也可以为模拟退火、禁忌搜索和迭代局部搜索等元启发式算法提供高质量初始解。

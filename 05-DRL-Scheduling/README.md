# 第五阶段：深度强化学习（DRL）+ 智能调度

## 学习目标
- 掌握深度强化学习基础理论
- 学习经典 DRL 算法：DQN → A3C → SAC → PPO → GRPO
- 学习 Decision Transformer（将 RL 转化为序列建模）
- 探索 DRL 在智能调度方向的应用

## 学习资源
- OpenAI Spinning Up：https://spinningup.openai.com/
- CleanRL（单文件 DRL 实现）：https://github.com/vwxyzjn/cleanrl
- 强化学习导论（Sutton & Barto）：http://incompleteideas.net/book/the-book.html

## 核心算法
| 算法 | 类型 | 特点 |
|------|------|------|
| DQN | 基于价值 | 经验回放 + 目标网络 |
| A3C | 基于策略 | 异步多线程 + Actor-Critic |
| SAC | 基于策略 | 最大熵 + 离线学习 |
| PPO | 基于策略 | 信赖域 + 简单高效 |
| GRPO | 基于策略 | 群组相对策略优化 |
| Decision Transformer | 序列建模 | 将 RL 视为序列预测 |

## 练手项目
- 使用 CleanRL 在 Gym 环境中跑通 DQN/PPO
- 实现一个简单的 Decision Transformer
- 调研智能调度相关论文和开源项目

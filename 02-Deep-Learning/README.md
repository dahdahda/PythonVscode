# 第二阶段：深度学习基础（吴恩达课程）

## 学习目标
- 掌握神经网络基本原理（前向传播、反向传播、梯度下降）
- 学习核心模型架构：MLP、CNN、RNN/LSTM、GNN
- 掌握 PyTorch 深度学习框架
- 在 GitHub 上找开源项目练手

## 学习资源
- 吴恩达深度学习课程：https://www.coursera.org/specializations/deep-learning
- PyTorch 官方教程：https://pytorch.org/tutorials/
- d2l.ai《动手学深度学习》：https://d2l.ai/

## 核心知识点
- MLP（多层感知机）：全连接网络、激活函数、反向传播
- CNN（卷积神经网络）：卷积层、池化层、经典架构（ResNet、VGG）
- GNN（图神经网络）：图卷积、消息传递、节点分类

## 练手项目
- MNIST 手写数字识别
- CIFAR-10 图像分类
- PyTorch 基础操作
